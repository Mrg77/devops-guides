opsforge 🔥
Un CLI qui installe ta boîte à outils DevOps, encadre la façon dont tu l'utilises (guards), et trace la sécurité de ta machine (SBOM, VEX, CVE).

agentguard 🛡️
Un pare-feu policy-as-code déterministe pour les tool-calls d'un agent IA. Local-first et Kubernetes-native : il intercepte l'action dangereuse d'un agent (quel outil, quelle cible, quel contexte) avant qu'elle n'arrive. Le frère d'opsforge, côté agents IA.
Lire le guide → · Repo README
KubeForge 🔨
Une console web local-first qui n'affiche pas seulement ton cluster Kubernetes — elle l'analyse : le Resource stack (le câblage d'un namespace bas→haut), FinOps (gaspillage, coûts), SecOps (score de posture), stockage, tendances, et un copilote IA qui répond à « pourquoi ce pod crash ? » depuis les vraies données. Bilingue, gratuit (Gemini/Groq). Un seul binaire Go, rien d'exposé. L'alternative open source honnête à Lens.
